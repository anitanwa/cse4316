# Legacy test-plan references (retained for historical context only)

`ieee829mtp.pdf` (IEEE Std 829-2008, *Standard for Software and System Test
Documentation*) and `STP Guide.doc` are **superseded**. IEEE 829 was withdrawn
and replaced by the **ISO/IEC/IEEE 29119** family:

- 29119-1:2022 — General concepts
- 29119-2:2021 — Test processes
- 29119-3:2021 — Test documentation (contains the current Test Plan item)
- 29119-4:2021 — Test techniques

For new work, use the modern template in **`../test plan latex/`**, which follows
ISO/IEC/IEEE 29119-3. These files are kept only so students can see the lineage.
